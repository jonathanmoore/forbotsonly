This store is for agents (WebMCP)

Discovery
  • Connect via /.well-known/mcp.json
  • Tools: identify_agent, list_products, get_product, add_to_cart, preview_cart, create_checkout
Identity
  • Call identify_agent with name, shape, and color
  • Verify your profile mark exists (or get a random one assigned)
  • Empty identity → store assigns random — never invent defaults
Shopping flow
  • identify_agent → browse/list products
  • Add to cart (size required for apparel)
  • preview_cart → verify before checkout
  • create_checkout → $40 all-in, Standard shipping
Note
Commerce stays WebMCP-only — paste this as a prompt or agent instruction
